# Meal Planner

A full stack meal planning app using the Edamam Meal Planner API.

## Stack
- React + Tailwind (frontend)
- Express (backend)
- Supabase (database + auth)
- Edamam Meal Planner API (recipe/meal plan generation)

## Database
- `meal_plans` — stores generated meal plans per user, cached to avoid re-calling Edamam
